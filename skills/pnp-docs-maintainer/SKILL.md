# PNP Docs Maintainer

Maintain lean project documentation.

## Enforce Documentation Boundaries

1. Keep root `README.md` short and navigational.
2. Keep developer docs in `docs/development/*` and testing docs in `docs/testing/*`.
3. Keep agent workflow instructions in `AGENTS.md` and agent skill files.
4. Prefer links to official docs over re-explaining standard tool usage.

## Execute Workflow

1. Remove duplicated or stale sections.
2. Keep docs task-oriented and project-specific.
3. Update cross-links after moves/renames.
4. Validate markdown formatting and consistency.
