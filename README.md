# pnp-app

Next.js App Router MVP for users, campaigns, characters, relationships, and notifications.

## Quickstart

```bash
cp .env.example .env.local
yarn supabase:start
yarn supabase:env:local
yarn dev
```

## Quality Gates

```bash
yarn typecheck
yarn lint
yarn test:run
yarn build
```
